# Чек-лист демо для Hack&Change

Бот: [@alfha_shag_bot](https://t.me/alfha_shag_bot)

## Перед демо

- [ ] В `.env` задан новый токен BotFather; `.env` не добавлен в Git.
- [ ] `docker compose ps`: `db` — healthy, `bot` — Up.
- [ ] `docker compose logs bot` не содержит `Traceback`, `RAG failed` или `ERROR`.
- [ ] Ollama запущена, доступны модели `qwen3:4b-instruct-2507-q4_K_M` и `bge-m3`.
- [ ] Репозиторий доступен жюри.

## Основной сценарий (2–3 минуты)

1. `/start` — приветствие и объяснение возможностей.
2. `/profile` — выбрать стадию, форму, налоговый режим, опыт и сферу.
3. Задать: `Как ИП на УСН уменьшить налог на страховые взносы?`
   - показать ответ;
   - показать блок «Источники» со ссылками.
4. Задать: `Какой налог платить?`
   - показать уточняющий вопрос.
5. Задать: `Как вырастить кактус?`
   - показать честный отказ, без выдуманного ответа.
6. `/courses` — показать персональную подборку и причины рекомендаций.
7. `/tax_reminders` — создать налоговые напоминания.
8. `/remind 15.11.2026 10:00 Проверить отчёт` — создать разовое напоминание.
9. `/reminders` — показать активные напоминания.
10. `/cancel_reminder ID` — отменить тестовое напоминание.

## Что сказать на защите

- RAG использует гибридный поиск: pgvector + полнотекстовый поиск PostgreSQL.
- Для каждого ответа бот показывает источники.
- При низкой близости бот не вызывает LLM и честно сообщает, что ответа нет в базе.
- Платные материалы индексируются только по названию и описанию.
- Профиль пользователя влияет на подбор курсов.
- Worker доставляет разовые и повторяющиеся напоминания.
- События сохраняются для метрик возврата.
