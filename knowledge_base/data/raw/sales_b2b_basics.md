# Продвинутые техники продаж для B2B

Курс для опытных предпринимателей: как выстроить системные продажи в сегменте B2B, работать с длинным циклом сделки и выстраивать отношения с закупщиками. 

В программе: квалификация лидов по BANT, работа с медианным чеком, отработка возражений на уровне закупочного комитета.
